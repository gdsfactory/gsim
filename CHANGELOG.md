# Changelog

See the [documentation changelog](https://gdsfactory.com/gsim/CHANGELOG/) or
[GitHub Releases](https://github.com/gdsfactory/gsim/releases) for release history.

Release Drafter generates release notes from merged pull requests. The documentation changelog is generated from
published GitHub releases during each docs build and refreshed after the Release workflow succeeds.

Do not add hand-written release entries here. Run `just sync-changelog` to regenerate `docs/CHANGELOG.md` locally.
